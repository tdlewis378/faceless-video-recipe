    AI setup note

    This browser preview uses a deterministic local recipe engine so the full flow works without exposing a secret key. To activate AI generation, proxy a JSON request through a server-side POST /api/generate-recipe endpoint, keep your provider key in a server environment variable such as OPENAI_API_KEY, validate the returned schema, and replace the local generator call in generateRecipe() with fetch('/api/generate-recipe', ...). Never put the key in this HTML or local storage.
